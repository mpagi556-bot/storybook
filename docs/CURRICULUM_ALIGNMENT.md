# Uganda primary curriculum metadata

The Story Library stores two optional teacher-entered fields:

- **Learning area / subject** – for example, Literacy I, Literacy II, English or Integrated Science.
- **Competence focus** – the specific performance or competence the teacher wants learners to demonstrate.

The NCDC's current primary-education FAQ states that P.1–P.3 have learning areas rather than subjects, that the thematic curriculum is implemented in P.1–P.3 only, and that primary assessment is formative and summative and assesses competences. It lists Literacy I and Literacy II among the P.1–P.3 learning areas and identifies the wider primary subject/learning-area structure. The app therefore stores a teacher-entered learning area/subject and competence rather than assuming that a single generic subject label fits every primary class.

The app displays these broad class-level labels:

| Class levels in this application | Label shown | Status |
|---|---|---|
| P.1–P.3 | Thematic learning areas | Directly reflects the NCDC FAQ description |
| P.4 | Post-thematic transition | Application grouping only; verify against the current syllabus |
| P.5–P.6 | Upper primary | Application grouping only; verify against the current syllabus |

The P.4 and P.5–P.6 labels are not represented as formal NCDC phase names. The labels are a navigation aid, not official NCDC validation. Teachers should consult the current syllabi and teacher guides from [NCDC](https://ncdc.go.ug/) before assigning a competence or publishing material.

## Assessment purpose

Tests now carry an optional **Formative / continuous** or **Summative** assessment label. This is metadata for teachers and reporting; it does not automatically convert the existing test engine into a complete continuous-assessment record system. Teachers still need to record other classroom evidence, practical performance and learner work where the curriculum requires it.

## AI and curriculum alignment

The AI story and question prompts receive the teacher-supplied learning area and competence focus. They explicitly avoid claiming official NCDC approval. AI output is saved as draft/unapproved content for teacher review. Teachers should check:

- the story and vocabulary suit the learners' level;
- the learning area/subject and competence focus match the current syllabus;
- assessment tasks measure the stated competence, not only recall;
- the material is linguistically and culturally appropriate;
- any local-language content is suitable for the school's medium-of-instruction context.

Bloom level is an assessment-design tag; it is not a substitute for curriculum competence. Teachers should check both dimensions.
