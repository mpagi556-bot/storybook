# Story content and licensing

Only import or publish stories that are:

- written by the school or the teacher;
- public domain;
- openly licensed with terms that permit the intended use; or
- used with written permission from the copyright holder.

Keep the author, source name, source URL and exact licence/permission record with each story. If a story is adapted, record that it was changed and follow the licence attribution requirements. A URL alone does not prove permission to copy a book or story.

Potential source catalogues to review individually:

- [African Storybook](https://africanstorybook.org/) – African-language story resources; verify the licence on each story.
- [StoryWeaver](https://storyweaver.org.in/) – read the licence and attribution requirements on each item.
- [Global Digital Library](https://digitallibrary.io/) – verify usage rights for each resource.
- [Book Dash](https://bookdash.org/) – check the licence on each book before reuse.
- [Bloom Library](https://bloomlibrary.org/) – verify individual resource licence and adaptation requirements.
- [Project Gutenberg / Gutendex](https://gutendex.com/) – use public-domain status only after checking the jurisdiction and edition.
- [Open Library API](https://openlibrary.org/developers/api) – use for catalogue metadata/covers only; it is not permission to reproduce book text.

For Uganda curriculum alignment, see [CURRICULUM_ALIGNMENT.md](CURRICULUM_ALIGNMENT.md) and consult the current [National Curriculum Development Centre](https://ncdc.go.ug/) materials and the [Uganda National Examinations Board](https://uneb.ac.ug/) guidance. This project does not automatically certify that generated stories or questions meet current NCDC/UNEB requirements. Teachers must review level, language, cultural suitability, curriculum fit and accuracy before publication.

The eight sample stories in migration 001 are original short examples written for this project and labelled as school-created content. Teachers should still review them before use with learners.
